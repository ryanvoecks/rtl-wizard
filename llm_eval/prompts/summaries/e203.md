### Design summary

This is the **Hummingbird E203** (Nuclei/SiFive-derived) RISC-V core — a small, low-power 32-bit MCU-class CPU implementing the RV32IMAC instruction set. It is a 2-stage, single-issue, in-order pipeline (IFU fetch → EXU execute/commit) with support for tightly-coupled memories (ITCM/DTCM), an ICB (Internal Chip Bus) based memory/bus interface, CSRs, interrupts/exceptions, and the **NICE** (Nuclei Instruction Co-unit Extension) interface for adding custom coprocessor instructions.

The core fetches instructions in the IFU (with a lightweight BPU branch predictor and a mini-decoder), then the EXU fully decodes, dispatches to the ALU/MULDIV/LSU-AGU/BJP/CSR units, tracks outstanding long-latency instructions via the OITF scoreboard, and commits in order (resolving branches and exceptions). Memory accesses go through the LSU to the BIU, which arbitrates ITCM/DTCM/external bus traffic over ICB. A rich library of generic SiRV building blocks (DFFs, FIFOs, ICB bus bridges to AXI/AHB/APB/Wishbone, SRAM controllers) underpins everything. Configuration is centralized via `config.v`/`e203_defines.v` macros.

### Key modules/files

**Configuration (included everywhere)**
- `e203_defines.v` — master parameter/macro header (widths, pipeline params, feature toggles); includes `config.v` which holds the user-tunable feature switches (address size, MUL/DIV, TCM presence, JTAG, IRQ sync, etc.). Almost every file `\`include`s these.

**Top-down hierarchy**
- `e203_cpu_top.v` → instantiates `e203_srams` (SRAM wrappers) and the CPU; top wrapper exposing external ICB ports, IRQ, JTAG/debug.
- `e203_cpu.v` → the integration level: instantiates `e203_clk_ctrl`, `e203_extend_csr`, the optional `e203_subsys_nice_core` (NICE coprocessor), `e203_core`, and the ITCM/DTCM controllers (`e203_itcm_ctrl`, `e203_dtcm_ctrl`).
- `e203_core.v` → the pipeline integration: wires together `e203_ifu`, `e203_exu`, `e203_lsu`, and `e203_biu`.

**IFU (instruction fetch) — under `e203_ifu.v`**
- `e203_ifu_ifetch.v` — fetch FSM/PC generation; instantiates `e203_ifu_minidec.v` (early/light decode for branch info) and `e203_ifu_litebpu.v` (lightweight branch predictor).
- `e203_ifu_ift2icb.v` — converts fetch requests into ICB bus transactions toward ITCM/system bus.

**EXU (execute) — under `e203_exu.v`** (the bulk of the logic)
- `e203_exu_decode.v` — full instruction decode; `e203_exu_regfile.v` — register file; `e203_exu_disp.v` — dispatch; `e203_exu_oitf.v` — Outstanding Instructions Track FIFO (scoreboard for long-latency ops, dependency/hazard checks).
- `e203_exu_alu.v` — ALU integration; instantiates the functional sub-units: `e203_exu_alu_rglr.v` (regular ALU ops), `e203_exu_alu_bjp.v` (branch/jump), `e203_exu_alu_lsuagu.v` (load/store address-generation unit), `e203_exu_alu_muldiv.v` (multiply/divide), `e203_exu_alu_csrctrl.v` (CSR access control), `e203_exu_alu_dpath.v` (shared datapath), and `e203_exu_nice.v` (NICE custom-instruction dispatch).
- `e203_exu_commit.v` — in-order commit; instantiates `e203_exu_branchslv.v` (branch resolution/flush) and `e203_exu_excp.v` (exception/trap handling).
- `e203_exu_wbck.v` / `e203_exu_longpwbck.v` — short and long-pipe write-back arbitration.
- `e203_exu_csr.v` — CSR register file/logic (works with `e203_extend_csr.v` for extension CSRs).

**LSU / memory / bus**
- `e203_lsu.v` → `e203_lsu_ctrl.v` — handles data loads/stores, splitting traffic to ITCM/DTCM/external bus over ICB.
- `e203_biu.v` — Bus Interface Unit; arbitrates IFU + LSU traffic to the external memory/peripheral ICB.
- `e203_itcm_ctrl.v` / `e203_dtcm_ctrl.v` — TCM controllers; `e203_srams.v` wraps `e203_itcm_ram.v` and `e203_dtcm_ram.v`.

**Support blocks**
- `e203_clk_ctrl.v` + `e203_clkgate.v` (clock gating), `e203_reset_ctrl.v`, `e203_irq_sync.v` (interrupt synchronizer).

**Generic library (`rtl/general/`)** — instantiated pervasively by the core:
- `sirv_gnrl_dffs.v` (the `sirv_gnrl_dfflr`/`dffr`/etc. flop primitives used everywhere), `sirv_gnrl_bufs.v` (pipe stages, CDC, FIFOs, bypass buffers), `sirv_gnrl_icbs.v` (ICB arbiters/buffers/splitters and bridges from ICB to AXI/AHB-Lite/APB/Wishbone), `sirv_gnrl_ram.v` + `sirv_sram_icb_ctrl.v`/`sirv_1cyc_sram_ctrl.v` (RAM + SRAM-over-ICB controllers), `sirv_sim_ram.v` (behavioral sim RAM), `sirv_gnrl_xchecker.v` (X-state assertion checking).

**NICE example (`rtl/subsys/e203_subsys_nice_core.v`)** — a sample custom coprocessor connected through the `e203_exu_nice.v` NICE interface, demonstrating how to extend the ISA with user-defined instructions.
